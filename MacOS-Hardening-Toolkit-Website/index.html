MacOS-Hardening-Toolkit

Two macOS privacy and security shell scripts, generated with privacy.sexy (v0.13.7, December 2024) from a hand picked tweak selection. The main script works through roughly 150 actions. Both scripts need administrator rights and make system wide changes, so read a script before you run it.

What gets cleared

privacy-script.sh clears shell histories, system and application logs, and diagnostic data. It clears browser data for Chrome, Safari, and Firefox, including histories, caches, cookies, and saved Firefox passwords. It clears developer and app caches (Homebrew, NPM, Yarn, Docker, Xcode, and others) and iOS device backups, empties the Trash, and clears the DNS cache.

Keeper's note, pinned under this label: deleted histories, passwords, logs, and backups do not come back. This part of the path only goes one way.

COURT / 02

What gets hardened

The same script resets macOS privacy (TCC) permissions: camera, microphone, accessibility, screen capture, contacts, calendar, photos, full disk access, and more. It disables telemetry for Firefox, Microsoft Office, Homebrew, .NET, and PowerShell, and removes the Google Software Update service. It disables Siri and remote management, remote Apple events, AirDrop, and Spotlight indexing. It enables the application firewall, firewall logging, and stealth mode, requires a password on wake, and disables guest access, remote login (SSH and SFTP), TFTP, and telnet.

COURT / 03

How to run each script

chmod +x privacy-script.sh security_enable.sh
./privacy-script.sh

The main script re-runs itself with sudo when it is not started as root. Each script pauses at the end waiting for a keypress; when stdin is not a terminal the pause is skipped and the scripts exit 0 on success. Read the section headers (the echo lines) first and remove anything you do not want before running.

security_enable.sh is mostly the revert companion for a different, smaller set of tweaks. It enables Gatekeeper if it is currently disabled, restores the downloaded file warning, and turns automatic software update checks, downloads, and installs back on. It does not revert anything privacy-script.sh does, and running it does not harden a system.

COURT / 04

Cautions and reversals

Settings changed by the scripts can mostly be changed back in System Settings. Deletions cannot: histories, logs, diagnostic reports, caches of record, and backups removed by privacy-script.sh are gone. The repo carries 7 tests, run with python3 -m unittest discover -s tests, which check both scripts with bash -n and test the Gatekeeper gate and quarantine loop from security_enable.sh against stubs. No Mac run is claimed by the suite.

Tests last checked against the live repo on 2026-11-01. An earlier version of this page said there were no test files and gave line counts for a four file snapshot; both were stale and have been corrected from the repo itself.
